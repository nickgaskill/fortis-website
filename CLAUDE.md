# Fortis Construction Group website

Public marketing site for Fortis Construction Group, a construction & remodeling company in Central Texas (Austin, Georgetown, Lakeway), owned by Nick Gaskill. Live via GitHub Pages; every push to `main` republishes the site automatically in about a minute.

## Architecture

Plain static HTML/CSS/JS — no framework, no build step. Thirty-seven real pages, each a full standalone page: `index`, `services` (an overview hub), `residential` (a landing page for the three residential categories), the three residential category pages (`interior-remodels`, `outdoor-living`, `home-additions-sunrooms`), `commercial-construction`, plus `portfolio`, `process`, `reviews`, `contact`, `pool-design-guide` (a virtual flip-book brochure), `pool-builder` (an interactive cost estimator), `design-your-pool` (a landing page linking to both), `fortis-haus` (the custom-home sub-brand page), `about`, `blog` (+ one post per article, e.g. `choosing-your-pool-style`), and one page per real project (`cimarron-hills`, `dovetail-lane` — each a hero + write-up + `.ch-grid` gallery with a click-to-open lightbox). `portfolio.html` also has a **"Browse by type" category gallery** (below the featured projects): a grid of `.catg` boxes generated by an inline script from the `#catgData` block — the single edit point. Each `<div data-cat data-label>` in that block holds the category's `<img>`s; the box cover is the first photo, the count is automatic, and clicking opens an inline `.clb` lightbox cycling that category. Empty category divs render a "Photos coming soon" placeholder box. CSS/JS for it are inline in `portfolio.html` (not styles.css). Boxes currently start empty — Nick adds his own photos per category; each `<div data-cat>` carries a commented `<img>` example.

- **Residential** (`residential.html`): a landing page, not a category page itself — a `page-hero` plus a three-tile `.tile-grid` (base 3-col class, no modifier needed) offering Interior Remodels, Outdoor Living, and Home Additions & Sunrooms. - The **header and footer are copy-pasted into all thirty-seven pages** — if you edit one (add a page link, change the phone number), make the same edit in every HTML file. The `aria-current="page"` marker is set on the current page's nav links (within Services, only Residential/Commercial Services/Pools/Design Your Pool/Fortis Haus self-mark this way today — the plain category links like Interior/Exterior never have, consistent with the site's original pattern).
- `styles.css` — all styling. The palette and fonts are CSS variables in `:root` at the top (`--navy` deep blue, `--gold`/`--gold-bright`, `--paper` warm cream, `--black`). Change a color there and it changes site-wide. The wordmark uses `--wordmark` (Cinzel), loaded from Google Fonts via a `<link>` in each page's `<head>` — the only external dependency. `section[id],[id].svc{scroll-margin-top}` keeps the sticky header from covering a heading when the Services dropdown jumps to an anchor.
- `site.js` — the Menu dropdown toggle (closes on outside-click, Escape, or link click) and scroll-reveal animations.

## Conventions

- Brand voice: plain, direct, confident. Tagline: "Built different. Built Fortis." The home hero opens with the Latin meaning of the name — "for·tis — Latin adj. — strong; steadfast; built to last" (the old "From the slab to the last coat of paint" kicker is retired).
- Business facts: phone (512) 743-9690, email Nick.Gaskill@fortistexas.com, Instagram @fortistexas. The four customer reviews are verbatim quotes — don't reword them.
- Gallery projects use real locations/dates. Photo placeholders are `<div class="proj-ph">` blocks; replace with `<img>` tags as real photos are added (compress images to ~200-400 KB before committing).
- **SEO layer** (canonical domain `https://www.fortistexas.com`): every page has a keyword-first `<title>`, meta description, `rel=canonical`, and og: tags; every non-home page carries JSON-LD BreadcrumbList, and the 22 service/category pages add a `Service` schema (provider → the `#business` @id, areaServed → 21 cities). `index.html` keeps the LocalBusiness/GeneralContractor schema. `sitemap.xml` (add new pages there!) and `robots.txt` live at the root. The footer's `.foot-areas` line lists served cities as visible text on every page. Note: canonicals/sitemap point at fortistexas.com, so SEO fully activates once the domain is pointed at GitHub Pages.
- To preview locally, open any `.html` file directly in a browser — no server needed.
